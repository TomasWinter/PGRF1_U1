Ovládání
- LMB - vytváření bodů
- RMB - úprava pozice bodu
- Enter - dokončení úpravy polygonu (vytvoření nového polygonu)
- V - přepnutí mezi vytvářením čáry a polygonu
- C - smazání všech tvarů
- Del - smazání bodu, který držíte pravým tlačítkem (Pouze pro polygony)
